How it works

The tool gives your Claude the game data and the Path of Building calculation engine. You just chat.

Get Claude Desktop

Install the Claude desktop app for Windows or macOS and sign in.

Install the tool

Download the .mcpb file from the latest release and double-click it, or add it in Claude → Settings → Extensions.

Describe your build

Start a new chat and say what you want to play. Claude asks a few questions, then builds the plan with you.

The first start downloads about 30 MB of public game data. Path of Building numbers are Windows-only for now; everything else works on macOS too.

What it does

Made for casual players: your idea comes first, not the current meta.

Asks before it builds

Campaign, fast mapping or bossing? How far do you want to push it? One button or several? Budget, softcore or Hardcore?

Real numbers

Damage, kill times, hits you survive and resistances, calculated by Path of Building's engine at every stage of the build.

Honest verdicts

If a build will struggle with your goal, Claude says so and offers options: tweak it, raise the budget or try a different setup.

Finds more damage

Tries support swaps, passives, Spirit skills and anoints, and keeps only changes that add damage without costing defence.

League-start plans

A plan for each campaign phase, with the skills and passives for each one and the quest rewards along the way.

In-game Build Planner

Writes the plan into the game's own Build Planner, one file per phase, so you can follow it while you play.

A guide page

Opens a build guide in your browser with each phase, your passive tree highlighted, gear to look for and the numbers.

Gear and extras

Stat priorities per slot, uniques that fit, jewels, flasks, charms, runes, soul cores, anoints and free-Spirit amulets.

Prices and trade links

Live Currency Exchange prices for currency and runes, and ready-made trade searches you open in your own browser.

Things to ask

Talk to it like a friend who knows the game.

"I want to summon a huge army and just walk through maps."
"League start: something with fire and big explosions, self-found."
"I'm level 72 with this character. Why is it dying so much?"
"Two-handed mace or one-handed and shield for my Titan? Compare them."

It's a beta

It works, but expect rough edges. Please report anything odd on GitHub.

  • Numbers are estimates: Path of Building with assumed gear, not your exact items.
  • Verdict targets are sensible rules of thumb, not official numbers.
  • Timeless jewels and Headhunter's stolen mods aren't calculated yet.
  • Prices for uniques and rares come from trade searches you open yourself.

Privacy

Everything runs on your PC.

  • No account, no tracking, no server of ours in between.
  • It downloads public data: GGG's passive tree export, RePoE and Path of Building data, and Currency Exchange prices.
  • It never touches the game client or your game account.

FAQ

Is it really free?

Yes. It's open source under the MIT license. Donations help, but they never unlock features.

Do I need a paid Claude plan?

You need the Claude desktop app. Long build sessions use a lot of conversation, so a paid plan gives more room, but the tool itself costs nothing.

Can it get me banned?

It doesn't read or change the game, doesn't automate anything and doesn't use your game account. It's a planning tool, like Path of Building or a build guide site.

Will it just give me the meta build?

No. It starts from what you want to play and tries to make that work. If your idea won't reach your goal, it tells you and suggests the closest thing that will.

Which game version does it use?

It downloads current data when it starts and refreshes when the game data changes. Path of Building's engine is bundled and updated with each release.

Like it? Buy me a coffee.

This is a free hobby project. Tips help keep it updated each league. They're thank-yous only and don't unlock anything.
